# Wick — Backend

This is the **backend** for Wick, a 5-minute binary price prediction market
on Stellar/Soroban. The frontend lives at
[Tijesunimi004/wick-app](https://github.com/Tijesunimi004/wick-app).

Users stake XLM on whether **BTC, ETH, SOL, or XLM** will close above or
below a reference price over a 5-minute window. Winners split the pot
proportionally minus a 2% fee. No AMM, no order book, no house edge.

**Testnet only.** This contract holds user funds — do not deploy to mainnet
without a security audit and legal review.

---

## What's in this repo

```
contracts/
  fair-market/     Soroban smart contract (Rust) — source of truth
  prediction/      Earlier prototype — kept for reference, do not modify
keeper/            Automates create_round + settle every 5 minutes
indexer/           Reads on-chain events → Postgres
api/               REST + WebSocket server for the frontend
packages/
  types/           TypeScript types generated from openapi.yaml
  bindings/        TypeScript contract bindings generated by stellar CLI
scripts/           Build, deploy, genesis, CORS helpers
fixtures/          Mock API responses for wick-app mock mode
docs/
  ARCHITECTURE.md  Round lifecycle, invariants, failure modes
  API.md           Endpoint reference (human-readable)
openapi.yaml       Machine-readable API contract (source of packages/types)
```

## Quick start — one command

```bash
cp .env.example .env
# Set CONTRACT_ID in .env (see Testnet addresses below)
docker compose up --build
```

API available at `http://localhost:3000`. Indexer starts polling testnet immediately.

## Manual setup

### Prerequisites

- Rust + `wasm32v1-none` target
- [Stellar CLI](https://developers.stellar.org/docs/tools/cli/install-cli) 25+
- Node.js 18+
- PostgreSQL 15+

### Deploy contract (testnet)

```bash
# Build optimised WASM
stellar contract build --package wick-fair-market --optimize

# Deploy — writes CONTRACT_ID to .env
bash scripts/deploy-testnet.sh

# One-time initialisation
bash scripts/init.sh

# Verify oracle is reachable
bash scripts/check-oracle.sh

# Open first rounds for all four assets
bash scripts/genesis.sh
```

### Run services

```bash
# Keeper — keeps rounds rolling automatically
cd keeper && npm install && npx ts-node src/index.ts

# Indexer — reads events into Postgres
cd indexer && npm install && npm run migrate && npm run dev

# API
cd api && npm install && npm run dev
```

## Generated artefacts

These files are committed so wick-app can vendor them without running generators:

| File | Generator | Command |
|---|---|---|
| `packages/types/index.ts` | openapi-typescript | `make types` |
| `packages/bindings/` | stellar contract bindings | `make bindings` |

Re-run `make types` after changing `openapi.yaml`.
Re-run `make bindings` after re-deploying the contract.

## Legal

A 5-minute up/down contract on an asset price is functionally a binary
option — a regulated instrument in many jurisdictions. This project is
testnet-only. Get legal advice before accepting real funds.
